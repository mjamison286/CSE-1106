# CSE 1106

CSE 1106 is a lab class that teaches about many things that computer scientists use in the real world.

## Description

This repo contains all of the code and other files created for my class. This includes coding projects and labs
as well as practice using things like git and github.

## Languages

This repo will contain mostly C and C++ code.

## How to Run

To run any of the code present in this repo, simply clone the repo and build your desired file using gcc.

Multi file projects will have their own folder associated with them and some may contain a cmakelists file for 
easier building.

## Goals for this project

I hope to become extremely comfortable when using the cli when doing regular everyday software development. This 
includes becoming proficient in using git commands and understanding the tools that real developers use every day.
